# FlipForge Brand Workspace Governance

This directory contains the workspace-level instructions used to keep FlipForge branding, public copy, visual implementation, and release changes consistent across AI-assisted work.

## Authority order

1. `../manifest.json`
2. `../spec/CARD_DECISION_INTELLIGENCE_LOCK.md`
3. `00_GEMINI_START_HERE.md`
4. `01_GEMINI_MASTER_BRAND_INSTRUCTIONS.md`
5. Remaining files in this directory as supporting implementation guidance

If a supporting document conflicts with the locked manifest or descriptor specification, the manifest and descriptor lock win.

## Current locks

- Brand: **FlipForge**
- Descriptor: **CARD DECISION INTELLIGENCE**
- Tagline: **Before you buy. Know Why.**
- Typeface: **Geist Sans**
- Core palette: white, silver, gold, deep gold, black / near-black

## Gemini / AI workspace use

When loading these files into an external AI workspace, start with `00_GEMINI_START_HERE.md` and `01_GEMINI_MASTER_BRAND_INSTRUCTIONS.md`, then add the copy dictionary, visual rules, checklists, asset map, request template, and `brand-tokens.json`.
