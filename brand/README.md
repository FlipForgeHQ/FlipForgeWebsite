# FlipForge Approved Brand Archive v2.1

Status: **APPROVED / LOCKED**  
Updated: 2026-09-04

This directory is the versioned GitHub storage location for the approved FlipForge identity.

## Locked identity
- Mark: four open corner forms framing a centered 3D gold cube.
- Descriptor: **CARD DECISION INTELLIGENCE**.
- Official logo-lockup campaign line: **Before you buy. Know Why.**
- Normal prose: **Before you buy. Know Why.**
- Primary typeface: **Geist Sans**. The licensed webfont is self-hosted in `assets/fonts/`.
- Palette: Black `#000000`, White `#FFFFFF`, Silver `#8B8F98`, Gold `#D4AF37`, Deep Gold `#B8860B`.

## Descriptor change
`CARD DECISION INTELLIGENCE` supersedes the previous `CARD INTELLIGENCE` logo descriptor as of 2026-09-04. Earlier wording may remain in historical documentation or product-module names, but it is no longer approved as the current FlipForge brand descriptor.
