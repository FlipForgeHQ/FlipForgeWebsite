# Live Production Parity Gate Checklist

This checklist defines the minimum proof expected from the automated production-parity hardening.

- [x] Public deploy manifest only; no production secret or Netlify token required.
- [x] Exact GitHub commit equality required.
- [x] Production context and `main` branch required.
- [x] Server-owned fail-closed app boundary required.
- [x] Production diagnostics separation required.
- [x] Smart Opportunity remains recommendation authority.
- [x] Existing PSA intelligence remains grading authority.
- [x] Browser recommendation authority remains false.
- [x] Transaction authority remains false.
- [x] Netlify convergence receives bounded retries.
- [x] PR validation checks syntax/wiring without touching production state.
- [x] Main push verification checks the real public production manifest.
- [x] Beta Complete static gate requires the parity gate to remain wired.
- [x] Signed-in live customer QA remains a separate mandatory gate.
