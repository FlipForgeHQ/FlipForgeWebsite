# FlipForge Public Site — Production Build Brief v1

**Status:** Approved production target  
**Scope:** Public marketing site  
**Branch:** PR #436 / `design/homepage-real-graphics-motion`  
**Release rule:** Do not merge to production until final visual QA is approved.  
**Brand:** FlipForge™ — Card Decision Intelligence™  
**Locked slogan:** **Before you buy. Know Why.**

## Creative objective

The public site must move beyond polished SaaS layout into a premium, cinematic product-launch experience. Every major page should contain custom composed visuals that explain the FlipForge product: exact identity, evidence qualification, supported value, uncertainty, decision, traceback, and outcome.

The approved standard is black / gold / white-silver, dimensional, collectible-aware, product-led, and visually explanatory.

## Global art direction

- Near-black / deep graphite backgrounds.
- Champagne gold as focused signal and illumination, not decoration.
- White / cool silver for slab and structural framing.
- Restrained green only for qualified/verified states.
- Restrained red only for rejected/blocked evidence.
- Directional edge light, halos, subtle particles and depth.
- Bold editorial typography with one dominant statement per scene.
- Real product cues embedded inside composed scenes.
- Motion language: **Resolve → Qualify → Reject → Recalculate → Lock → Reveal**.
- Reduced-motion mode must preserve all information.

Avoid generic SaaS card grids, stock imagery, clip-art, decorative gold borders, scanning lasers, tiny dashboards, repeated disclaimers, fabricated metrics, the retired slogan “Signal. Confidence. Advantage.”, and the forbidden former homepage asset `assets/images/flipforge-approved-decision-visual.webp`.

## Sitewide visual rule

Every major public page must contain:
1. one hero-grade composed visual,
2. one supporting explanatory graphic,
3. one premium branded close / CTA treatment.

A graphic is not decoration. It must answer a real product question.

# Asset production

Desktop master: 1600×900 or 1920×1080.  
Mobile: deliberate vertical composition, not a shrunken desktop crop.

Prefer WebP / AVIF for raster art and SVG for clean interface diagrams. Lazy-load below-the-fold graphics. Reserve image aspect ratio to prevent layout shift.

Naming:
`ff-[page]-[concept]-v1.[webp|avif|svg]`

# Acceptance gate

A page is not visually finished unless:
- official FlipForge identity is correct,
- the hero contains a real composed visual,
- the visual explains a real product behavior,
- quality matches the approved cinematic references,
- mobile has a deliberate composition,
- motion is product-connected and reduced-motion safe,
- no unsupported metric or claim appears,
- assets are optimized and do not cause layout shift,
- the page feels unmistakably FlipForge.

**Final standard:** when a section could belong to any SaaS company after replacing the logo, it is not finished.
