# Homepage Navigation V1

Purpose: keep the public FlipForge homepage as the default entry point and expose the current customer-facing public destinations without changing the approved homepage structure.

Public homepage navigation order:

1. Home
2. Product
3. Decision Intelligence
4. Evidence Lab
5. Launch Plans
6. About
7. Connect
8. Request Beta Access

Rules:
- The FlipForge logo and Home link resolve to `/`.
- Loading `/index.html` normalizes to the canonical root `/` without changing the page content.
- Decision Intelligence and Connect are discoverable directly from desktop and mobile navigation.
- The homepage hero and Deal Check remain unchanged.
- The first prominent homepage descriptor uses `Card Decision Intelligence™`; the locked logo asset itself is not altered.
- The expanded navigation switches to the mobile drawer before the desktop row becomes crowded.
