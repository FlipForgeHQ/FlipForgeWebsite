# FlipForge Card Decision Intelligence™ — Wave 1 Learning Scorecard v1

Status: **BETA LEARNING CONTRACT**

## Purpose

Measure whether active private-beta testers understand the Card Decision Intelligence experience without treating tester opinion as product accuracy, market performance, or recommendation authority.

## Four structured signals

Each optional 30-second comprehension check records only:

1. **Decision understood** — yes / partly / no.
2. **Next step clear** — yes / partly / no.
3. **Evidence impact** — increased confidence / no change / decreased confidence / evidence not viewed.
4. **Most useful CDI layer** — Identity / Evidence / Economics / Risk + Uncertainty / Decision / Decision Receipt / Outcome / None yet.

## Privacy boundary

The structured fields do not contain card identity, listing URL, account ID, recommendation inputs, provider credentials, or transaction data. The existing authenticated tester feedback endpoint and operator-only review boundary remain authoritative.

## Operator interpretation

The operator scorecard reports counts, not accuracy percentages. For Wave 1, the key questions are:

- Can testers understand the decision quickly?
- Do they know what to do next?
- Does evidence increase or decrease confidence?
- Which CDI layer is doing the most comprehension work?

Small-sample results should be treated as directional product-learning evidence only.

## Expansion rule

Do not use the scorecard alone to expand the cohort. Expansion beyond the first five still requires activation, real use, qualitative feedback, and S1/S2 defect review under Issue #302.
